# MiComunidad

Plataforma multi-edificio para la gestión centralizada de comunidades.

## Arquitectura

- Mobile: React Native + Expo
- Web: Next.js
- Backend: Supabase
- Database: PostgreSQL
- Payments: Transbank Webpay

## Estructura

- `apps/mobile` — Aplicación Android/iOS
- `apps/web` — Plataforma web
- `packages` — Código compartido
- `supabase` — Backend, migraciones y funciones
- `docs` — Documentación del proyecto
